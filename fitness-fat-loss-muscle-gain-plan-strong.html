🔥 减脂增肌方案

88kg · RMR 1726 · 骑车通勤 · 游泳 + 力量 · 月减 3kg

一、核心原则

热量差 ≠ 只管饿

减肥底子是热量赤字（消耗 > 摄入），但激素环境和体成分决定了这个赤字是减脂还是掉肌肉。

概念说明
体成分不是"多重"，而是脂肪 vs 肌肉的比例。减肥目标 = 降脂肪、保/增肌肉
激素环境身体指令系统，决定热量缺口优先烧脂肪还是掉肌肉

1kg 肌肉 每天静息消耗 ≈ 13-15 kcal  |  1kg 脂肪 每天静息消耗 ≈ 4-5 kcal

体成分拆解

体重 = 脂肪量 + 瘦体重（肌肉 + 骨骼 + 水分 + 器官）

A：75kg / 体脂 25% → 外观松垮 → 代谢低
B：75kg / 体脂 12% → 精干 → 代谢高

目标：降脂肪、保/增肌肉 → 改善体成分

二、有氧 vs 无氧燃脂对比

有氧（稳态）无氧 / 力量 / HIIT
燃脂时机运动中优先脂肪EPOC 持续燃脂
单次消耗绝对值高运动中低，EPOC 多烧 6-15%
对肌肉过量会分解肌肉刺激肌肉生长信号
代谢提升短效，停就没了长期提升基础代谢

结论：力量训练是长期燃脂效率更高的主角，有氧是辅助。

三、激素环境 — 四巨头的博弈

各激素在减脂期的角色

激素         作用                            减脂期你要它
─────────────────────────────────────────────────────────
胰岛素      把血糖送进细胞                  训练后高（送碳水和蛋白进肌肉）
（储存激素）    多了→囤脂                 其他时间要控制

皮质醇      分解肌肉→升糖→囤内脏脂肪       越低越好（尤其晚上）
（压力激素）

睾丸酮      促进肌肉合成→提高代谢           越高越好
（合成激素）

生长激素    促进脂肪分解→保护肌肉           越高越好

减脂期常见翻车场景

场景结果
🚫 每天饿着 + 大量有氧肌肉流失，代谢下降，反弹
🔴 力量训练 + 吃够蛋白 + 睡好脂肪掉，肌肉涨，越减代谢越高
🚫 长期低脂饮食（< 0.6g/kg）睾丸酮↓↓ 没劲，掉肌肉
体成分 = 脂肪和肌肉的比例  ·  激素环境 = 身体的指令系统
指令对了 → 热量赤字优先烧脂肪；错了 → 饿肚子也掉肌肉，脂肪还在

四、抑制皮质醇（重中之重）

皮质醇管理优先级

1 训练后立刻补碳水

练后 30min 内吃 40-80g 碳水 → 刺激胰岛素 →
胰岛素是皮质醇的天然拮抗剂 → 皮质醇降下来

2 睡够 7h+（23:00-06:30）

睡眠不足 = 皮质醇全天高 20-30%。

3 单次运动时长 < 60min

时长皮质醇反应
0-40min正常上升，运动后快速回落
40-60min偏高但可控
60-90min+持续高位，恢复慢
> 90min皮质醇峰值，睾丸酮明显受抑

4 避免连续高强度   5 训练后 5min 冷身 + 深呼吸   6 运动结束到上床至少留 1h

皮质醇预警自查（≥2 条说明需要减量）

□ 早上醒来很累，不想起
□ 白天容易烦躁、焦虑
□ 难入睡或半夜醒
□ 练完恢复慢
□ 突然特别想吃甜的
□ 运动表现下降
□ 腹部脂肪没减掉，其他部位瘦了但肚子还在

五、运动后饮食策略

🔴 无氧（力量）后 → 必须补碳 + 蛋白

30-60min 内：
  蛋白质 20-40g（乳清蛋白 / 鸡胸 / 鸡蛋）
  碳水  0.5-1g/kg 体重（米饭 / 香蕉 / 红薯）
  脂肪  少量即可

✅ 有氧（游泳/跑步）后

强度需要补什么
低强度不需要特别补
中高强度（游泳 45min）10-20g 蛋白 + 少量碳水

八、实战餐单

🔴 训练日

早餐（~8:00）
  全蛋 3 个 + 燕麦 60g + 牛奶 200ml
  ≈ 45g 蛋白 / 50g 碳水 / 20g 脂肪

午餐（~12:30）
  米饭 200g + 鸡胸/瘦牛肉 200g + 绿叶菜随意
  ≈ 50g 蛋白 / 60g 碳水 / 10g 脂肪

🔴 练后餐（~18:30）← 最重要的一顿
  米饭 250g + 三文鱼/鸡腿/瘦猪肉 200g + 蔬菜
  或：蛋白粉 2勺 + 香蕉 2根 + 馒头 1个
  ≈ 55g 蛋白 / 80g 碳水 / 10g 脂肪

晚餐（~20:30）
  红薯 150g + 虾/豆腐 150g + 蔬菜
  ≈ 35g 蛋白 / 35g 碳水 / 10g 脂肪

✅ 休息日

早餐 同上
午餐 米饭减到 150g，其他不变
晚餐 不吃主食或只吃半碗红薯，🔴 蛋白质照常吃够
