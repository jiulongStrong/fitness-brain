🔬 科研与临床中用来"测量"神经类型的客观指标

按从简单到复杂排序，括号内标注对应测量什么类型

① 惊跳反射 (Startle Response) — 反射级

给受试者突然的噪音（通常 95dB 白噪声突声），用眼轮匝肌 EMG 记录眨眼强度。

  • 反应强且恢复慢 → 高神经质 / 高 BIS / HSP（杏仁核高反应）
  • 反应弱且恢复快 → 低敏感 / 低神经质

② 皮肤电导反应 (SCR) — 自主神经级

测量手心汗腺的极微小出汗（交感神经驱动）。给情绪刺激或中性刺激。

  • 基线电导高 + 反应幅度大 → HSP / 高神经质 / 交感主导
  • 基线低 + 反应小 → 低敏感 / 蒲公英型
  • 刺激后快速回落到基线 → 腹侧迷走调节好（自主灵活性高）

③ 心率变异性 (HRV) — 自主神经调节级

通过 ECG 记录逐次心跳间隔的变异。高频 HRV（0.15-0.4Hz）反映副交感（迷走）活性。

  • 高静息 HRV + 任务时适度下降 → 腹侧迷走占优、情绪调节好
  • 低 HRV + 过度下降 → 交感为主、易过载（常见于 HSP）
  • HRV 长期极低 → 背侧迷走冻结型

④ EEG / ERP — 皮层电活动级

用脑电图记录事件相关电位（ERP），特别是：

  • P300 波幅大 — 对新异刺激意外大 → 深度加工（HSP）
  • 静息 α 波不对称（左前额 > 右前额） → 趋近倾向 / 高 BAS
  • 右前额 α 弱（即右前额更活跃） → 回避倾向 / 高 BIS / 高神经质
  • 听觉脑干反应 (ABR) 阈值低 — 感觉门控开放大 → HSP

⑤ fMRI — 脑功能定位级

上面所有维度的最终验证：

  • 前脑岛 + ACC + PFC 对他人情绪图片反应更强 → HSP
  • 伏隔核 / 腹侧被盖区对奖励线索反应强 → 高 BAS / 高感觉寻求
  • 杏仁核对恐惧面孔反应强 + 与 PFC 连接弱 → 高神经质 / 高 BIS
  • DMN 在休息时连接弱 → 低内向 / 低反思

⑥ 量化脑电图 (qEEG) + 微状态分析 — 网络动态级

分析静息态下 EEG 微状态（微秒级脑网络切换模式）：

  • 微状态 C（突显网络）占比高 + 切换慢 → HSP — 沉浸在深度加工中，不易转移注意力
  • 微状态 D（注意力网络）切换快 → 低敏感 / 高外向

⚡ 现实中，个体差异是连续谱而非二分——HSP vs 非HSP，内向 vs 外向，都不是"有/无"的关系。 大多数人是在五个维度上各自落在某个位置，组合成独特的神经模式。 本页的问卷可以让你用 5 分钟大致了解自己的倾向。
