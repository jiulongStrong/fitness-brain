🎬 Joanna 动作指南

零基础版 · 不要追求重量，先把动作做对。错了不如不做。

🍑 臀腿动作

1. 徒手深蹲（入门）

准备：双脚与肩同宽，脚尖微微向外
下蹲：想象屁股去够身后的椅子
     → 膝盖对准脚尖方向，不要内扣
     → 大腿平行地面即可
起身：脚跟踩地，屁股夹紧站起来
呼吸：下蹲吸气，起身呼气
怎么做✅ 正确❌ 错误
椅子辅助背后放椅子，蹲到碰椅面就起蹲太深 → 屁股眨眼
脚跟垫高脚后跟垫小毛巾，更容易蹲膝盖内扣
进阶手持哑铃在胸前（酒杯深蹲）弯腰驼背

2. 臀桥（沙发/地上均可）

准备：躺地上/瑜伽垫，双膝弯曲，脚掌踩地
     → 手臂放身体两侧，掌心向下
发力：臀部夹紧，把骨盆往上推
     → 肩到膝成一条直线
     → 到顶部停1秒，夹紧
下落：缓慢放下，不要砸地
呼吸：起的时候呼气，落的时候吸气
✅ 感觉臀部酸 — 说明发力对了    ✅ 腰部不酸 — 说明骨盆没过度前倾
进阶：单腿臀桥（一条腿伸直，另一条做）

3. 蚌式开合（练臀中肌，改善屁股侧面凹陷）

准备：侧躺，膝盖弯曲成90°，双脚并拢
发力：膝盖像蚌壳一样打开
     → 脚掌始终贴在一起不分开
     → 到顶部停1秒
下落：缓慢放下
每侧：12-15次，然后换边

💪 上身动作

4. 靠墙天使（改善圆肩驼背的神器）

准备：背靠墙站，脚离墙一脚距离
     → 后脑勺、背、屁股都贴墙
     → 手臂弯曲成W形贴墙
动作：手臂贴着墙慢慢往上滑，到Y形
     → 再慢慢滑回W形
全程：手臂、后背不离开墙壁
每组：10-12次，做2-3组
🔑 每天都做一遍，站着等水开、等电梯都能做。

5. 哑铃划船（练背，改善虎背熊腰）

准备：一手撑椅子/沙发，同侧膝盖跪上去
     → 另一手拿哑铃，自然下垂
     → 背打平，不要弓背
发力：哑铃贴着大腿往后拉到手肘超过身体
     → 肩胛骨夹紧
下落：控制着放回去
每侧：10-12次，然后换边
✅ 正确❌ 错误
背打平像桌面弓背/塌腰
手肘夹着身体拉手肘飞出去
感觉背中间酸感觉手臂酸（太重了）

6. 哑铃卧推（练胸+手臂）

准备：躺地上/瑜伽垫上，膝盖弯曲
     → 双手各拿一个哑铃，手臂伸直在胸口正上方
     → 手肘不要完全锁死
下落：手肘向两侧打开，哑铃下降到胸两侧
     → 上臂与地面45°角，不要90°（保护肩膀）
发力：推回起始位置

🧘 核心动作

7. 死虫式（护腰入门核心）

准备：躺平，手臂伸直举在胸口上方
     → 膝盖抬起90°，小腿与地面平行
动作：右手和左脚同时伸直放下
     → 离地面一拳距离停住
     → 收回，换左手和右脚
全程：腰贴地，不要弓起来
每侧：8-10次

8. 平板支撑

准备：俯卧，手肘在肩膀正下方撑地
     → 脚尖点地，身体成一条直线
     → 收紧腹部和臀部
注意：不要塌腰，不要屁股抬太高
时间：从20-30秒开始，慢慢加到45-60秒
🚫 月经期不做平板支撑！ 用死虫式替代。

9. 鸟狗式（核心稳定+协调）

准备：四足跪姿，手在肩正下方，膝在髋正下方
     → 背打平，不要弓背塌腰
动作：同时伸直右手和左腿
     → 手臂和腿与地面平行
     → 停1秒，收紧核心
全程：身体不能歪，骨盆不能转
每侧：8-10次

📊 常见问题排查

问题原因怎么办

脖子酸用脖子代偿下巴微收，别仰头
膝盖响但不痛热身不够做5-10个徒手深蹲热身
膝盖痛姿势不对停！检查膝盖是不是对准脚尖
手抖重量太重/累了减重量或休息30s
